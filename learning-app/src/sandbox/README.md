# 离线练习沙盒

这是浏览器内的教学解释器，不是容器、虚拟机或完整 Bash。命令只处理当前终端内存中的样本，不调用操作系统、`eval`、真实网络或软件仓库。

## 入口与范围

- `createSandbox(distro)` 创建独立环境；`executeSandbox(state, command)` 返回新状态、输出、退出码与任务完成标记，不修改调用者传入的状态。
- `supportedCommands(id)` 是界面和 `help all` 使用的实际支持范围：Kali 67、Parrot 69、BlackArch 65、Pentoo 68 个入口，仅支持列明的选项。
- `man [章节] 命令` 使用现有命令手册数据，包含中文说明、选项、例子、官方参考链接，并区分“能阅读”与“能模拟执行”。
- 文件、当前目录、变量、权限、历史、软件包数据库和服务状态会在当前组件会话中延续。刷新、卸载组件或确认重置后清空，不写入学习笔记或云端账户。
- `systemctl` 的操作会影响 `ss`、`ps`、`pgrep`、`journalctl` 和本机 HTTP 样本；远程 `lab-target` 是另一个固定样本。
- 包版本带有 `sim` 标记；硬件和系统查询是教学快照，不代表访问者的电脑或真实发行版版本。
- Pentoo 的 `emerge` 只模拟搜索、环境信息、索引同步和只读预览，`equery` 提供 list/files/uses 子集，`eselect` 只列样本；不编译或安装软件，不计算真实依赖。
- Pentoo 明确选用 OpenRC 教学模型：`rc-service` 更改运行状态，`rc-update` 只更改 default 关联，两者互不替代。实际镜像应先确认 init；lab-web 并非真实系统默认服务。

## Shell 子集

支持引号和转义、简单环境变量、文件名 `*`/`?`、管道、标准输出覆盖和追加、标准输入重定向、`;`、`&&`、`||`。参数大小写保留，例如 `pacman -Ss` 与 `-ss` 不等价。

不支持脚本解释、循环、子 Shell、命令替换、后台任务、文件描述符重定向、here-document、交互编辑器和完整正则表达式。变量展开不执行 Bash 分词；混合引号通配符、符号链接、用户组继承、ACL 和特殊权限位不在当前教学模型中。`grep -F` 支持字面量，其余仅普通文本和首尾锚点，以避免任意正则阻塞页面。

每条命令先在状态副本上操作，抛出错误时回滚该条命令的虚拟变更（真实 Shell 多文件操作可能部分完成）。管道阶段的 cwd/变量独立，但虚拟文件和服务等外部状态共享。输出按标准输出和错误分开收集，不模拟字节级交错或终端分页。

## 限制与测试

每次输入上限 4096 字符和 32 条组合命令；单文件 64 KiB，全部文件 1 MiB，最多 500 个文件/目录；结果最多展示 400 行，保存最近 200 条输入历史。写操作只允许家目录子路径或 `/tmp`，系统文件是只读样本。

运行 `npm test` 检查解析、文件链式操作、管道、权限、分系统命令、内置课程题与资源限制。`npm run dev` 后访问 `/tests/sandbox-preview.html` 可在不解锁课程、不登录账户的情况下测试真实终端组件；此测试入口不进入生产构建。
